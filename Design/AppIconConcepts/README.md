# Paste app icon concepts

Generated with the installed `design-playful-app-icons` skill and the built-in image generation tool.

## Product brief

- Object: clipboard-history card
- Action: retrieve and paste again
- Emotion: clever, quick, friendly
- Platform: macOS
- Export: opaque 1024 × 1024 PNG, sRGB, no baked corner mask

## Concepts and quality report

### 01 — Memory Card Stack

- Lane: `soft_3d_object_character`
- Metaphor: saved cards + resurfacing + friendly speed
- Palette: `violet_tech` with the current icon's warm peach background
- Signature hook: the top card bends forward like a springy page
- Score: 91/100
- Small-size result: the three-layer stack remains clear at 32 px; the retrieval action becomes subtler
- Production status: concept-ready; best continuity with the current Paste icon

### 02 — Clipboard Courier

- Lane: `flat_outlined_mascot`
- Metaphor: clipboard + carrying a recalled card + energetic attitude
- Palette: `playful_lime` on deep violet
- Signature hook: the oversized top clip doubles as swept-back brows
- Score: 90/100
- Small-size result: silhouette, eyes, and carried card survive at 32 px
- Production status: concept-ready; refine the top clip before production because it can read as a hat brim

### 03 — Return Portal

- Lane: `minimal_dimensional_glyph`
- Metaphor: card + retrieval portal + precise reuse
- Palette: `dark_professional`
- Signature hook: the negative space creates a return path while one card terminal emerges
- Score: 92/100
- Small-size result: the portal and emerging card remain the clearest silhouette at 32 px
- Production status: strongest production candidate; professional and distinctive in the Dock

### 03 — Return Portal

```text
Use case: logo-brand
Artifact and platform: production-quality macOS app icon concept, square 1024 x 1024 visual, opaque sRGB appearance, full-bleed artwork with NO baked rounded-corner mask.
Product purpose and metaphor: Paste is a fast clipboard-history utility for capturing, searching, and reusing copied text, code, links, and images. Create one original abstract glyph derived from the action of a saved card passing through a retrieval portal and returning to the front. It should communicate history resurfacing, not merely storage. Emotion: precise, clever, quietly playful.
Pose, crop, silhouette: one continuous interlocking form centered in the square, filling about 72% of the canvas. Construct it from a thick rounded ribbon that folds into a square portal, with one broad card-shaped terminal emerging toward the viewer. The whole glyph must remain a single readable solid silhouette with an intentional asymmetric opening; use 2 to 4 broad masses and protect 12% margin.
Visual lane: minimal_dimensional_glyph. No face. Original action-derived mark, not a letter or monogram. Restrained shallow dimensional relief, one wide bevel family, strong optical balance without perfect symmetry.
Signature hook: exactly one memorable hook — the negative space inside the portal forms a subtle return path while the emerging terminal feels like a clipboard card, without using an arrow.
Palette: dark_professional — dominant ink black #121212, contrast electric violet #AC46EA, neutral soft white #F8F6F5, optional sky blue #3FA1F9 only as a restrained focal edge. Quiet full-bleed soft-white to very pale cool-gray background; maximum three visual color roles.
Material, light, depth: frosted acrylic/soft plastic, broad upper-left highlight, shallow extrusion, restrained ambient occlusion at the one overlap, short diffuse shadow. Crisp outer edge and strong grayscale contrast.
Small-size requirement: at 32 px, only the bold return-loop silhouette and emerging card terminal must remain; no internal decoration.
Negative constraints: no text, no letters, no P monogram, no command-key symbol, no literal arrow, no face, no generic refresh circle, no chain-link symbol, no generic infinity symbol, no clipboard checklist lines, no tiny details, no thin strokes, no busy pattern, no hard chrome, no excessive symmetry, no photorealism, no watermark, no border, no baked app-icon corner mask, no existing logo, no known character, no artist or studio imitation. Original abstract silhouette.
```
